## 3. 关键接口定义

### 3.1 Agent 循环接口

```python
class AgentLoop:
    """Agent ReAct 循环主体"""

    def __init__(
        self,
        config: AgentConfig,
        tools: list[ToolDefinition],
        channel: Channel,
    ):
        self.config = config
        self.tools = ToolRegistry(tools)
        self.channel = channel
        self.state_machine = StateMachine()
        self.turn = 0
        self.messages: list[Message] = []

    async def run(self, user_message: str) -> str:
        """
        运行循环，返回最终回复。

        流程：
        1. 发射 user_message 事件
        2. 循环执行每一轮，直到终止条件满足
        3. 发射 loop_end 事件
        """
        self.state_machine.transition("start")

        # 发射用户消息事件
        await self.channel.emit(Event(
            type="user_message",
            timestamp=now_ms(),
            turn=0,
            data={"content": user_message, "role": "user"},
        ))
        self.messages.append(UserMessage(content=user_message))

        result = None
        while self.turn < self.config.max_turns:
            # 检查取消
            if self.config.cancel_token.is_cancelled():
                await self._handle_cancel()
                break

            # 执行一轮
            result = await self._run_turn()

            # 判断终止
            if result.should_terminate:
                await self.channel.emit(Event(
                    type="turn_end",
                    timestamp=now_ms(),
                    turn=self.turn,
                    data={"reason": result.reason},
                ))
                break

            self.turn += 1
        else:
            # max_turns 达到上限
            result = TurnResult(
                should_terminate=True,
                reason="max_turns",
            )
            await self.channel.emit(Event(
                type="turn_end",
                timestamp=now_ms(),
                turn=self.turn,
                data={"reason": "max_turns"},
            ))

        # 发射 loop_end
        await self.channel.emit(Event(
            type="loop_end",
            timestamp=now_ms(),
            turn=self.turn,
            data={
                "total_turns": self.turn,
                "termination_reason": result.reason if result else "unknown",
            },
        ))
        self.state_machine.transition("terminate")

        return result.final_reply if result else ""

    async def _run_turn(self) -> TurnResult:
        """执行一轮：调 LLM → 解析 → 判断终止 → 执行工具 → 回填"""
        # 1. 调用 LLM
        response = await self._call_llm()

        # 2. 发射 thinking / text 事件
        if response.thinking:
            await self.channel.emit(Event(
                type="thinking",
                timestamp=now_ms(),
                turn=self.turn,
                data={"content": response.thinking},
            ))
        if response.text:
            await self.channel.emit(Event(
                type="text",
                timestamp=now_ms(),
                turn=self.turn,
                data={"content": response.text},
            ))

        # 3. 判断终止
        if response.stop_reason == "end_turn" or not response.tool_calls:
            await self.channel.emit(Event(
                type="final_reply",
                timestamp=now_ms(),
                turn=self.turn,
                data={"content": response.text},
            ))
            return TurnResult(
                should_terminate=True,
                reason="end_turn" if response.stop_reason == "end_turn" else "no_tool_calls",
                final_reply=response.text,
            )

        # 4. 执行工具
        self.state_machine.transition("tool_call")
        executor = ToolExecutor(self.tools, self.config)
        tool_results = await executor.execute_batch(
            response.tool_calls,
            context=self._build_tool_context(),
            channel=self.channel,
        )
        self.state_machine.transition("tool_done")

        # 5. 发射 tool_result 事件
        for tc, tr in zip(response.tool_calls, tool_results):
            await self.channel.emit(Event(
                type="tool_result",
                timestamp=now_ms(),
                turn=self.turn,
                data={
                    "tool_call_id": tc.id,
                    "tool_name": tc.name,
                    "result": tr.output,
                    "is_error": tr.is_error,
                },
            ))

        # 6. 结果回填
        self.messages.append(ToolMessage(
            tool_calls=response.tool_calls,
            results=tool_results,
        ))

        return TurnResult(should_terminate=False)

    async def _call_llm(self) -> LLMResponse:
        """调用 LLM（带重试）"""
        return await retry_with_backoff(
            func=lambda: self.llm_client.call(
                system=self.config.system_prompt,
                messages=self.messages,
                tools=self.tools.to_schema(),
                timeout=self.config.llm_timeout_ms,
            ),
            max_retries=self.config.max_retries,
            base_delay=self.config.retry_base_delay,
        )

    async def _handle_cancel(self):
        """处理取消"""
        self.state_machine.transition("cancel")
        await self.channel.emit(Event(
            type="cancelled",
            timestamp=now_ms(),
            turn=self.turn,
            data={"reason": "user_cancelled"},
        ))
        self.state_machine.transition("cleanup_done")
```

### 3.2 状态机接口

```python
class State(Enum):
    IDLE = "idle"
    RUNNING = "running"
    TOOL_EXECUTING = "tool_executing"
    PLAN_ONLY = "plan_only"
    CANCELLED = "cancelled"
    TERMINATED = "terminated"


class StateMachine:
    """状态机——管理 Agent 循环的状态转换"""

    TRANSITIONS = {
        (State.IDLE, "start"):              State.RUNNING,
        (State.RUNNING, "tool_call"):       State.TOOL_EXECUTING,
        (State.TOOL_EXECUTING, "tool_done"): State.RUNNING,
        (State.RUNNING, "terminate"):       State.TERMINATED,
        (State.RUNNING, "cancel"):          State.CANCELLED,
        (State.TOOL_EXECUTING, "cancel"):   State.CANCELLED,
        (State.CANCELLED, "cleanup_done"):  State.TERMINATED,
        (State.RUNNING, "enter_plan_only"): State.PLAN_ONLY,
        (State.PLAN_ONLY, "exit_plan_only"): State.RUNNING,
    }

    def __init__(self):
        self._state = State.IDLE

    @property
    def state(self) -> State:
        return self._state

    def transition(self, action: str):
        key = (self._state, action)
        if key not in self.TRANSITIONS:
            raise IllegalStateTransition(
                f"非法状态转换: {self._state.value} + {action}"
            )
        self._state = self.TRANSITIONS[key]

    def is_terminal(self) -> bool:
        return self._state == State.TERMINATED

    def is_cancelled(self) -> bool:
        return self._state == State.CANCELLED
```

### 3.3 工具执行器接口

```python
class ToolExecutor:
    """工具执行器——批量执行、并发/串行、超时、hook"""

    def __init__(self, registry: ToolRegistry, config: AgentConfig):
        self.registry = registry
        self.config = config
        self.hooks: list[ToolHook] = []

    async def execute_batch(
        self,
        tool_calls: list[ToolCall],
        context: ToolContext,
        channel: Channel,
    ) -> list[ToolResult]:
        """
        批量执行工具。

        策略：
        - 读类工具：并发执行（asyncio.gather）
        - 写类工具：串行执行（逐个）
        - 读类全部完成后才开始写类
        """
        # 分类
        read_calls, write_calls = self._classify(tool_calls)
        results: list[tuple[ToolCall, ToolResult]] = []

        # Phase 1: 读类并发
        if read_calls:
            read_results = await asyncio.gather(
                *[self._execute_single(tc, context, channel) for tc in read_calls],
                return_exceptions=True
            )
            results.extend(zip(read_calls, read_results))

        # Phase 2: 写类串行
        for tc in write_calls:
            result = await self._execute_single(tc, context, channel)
            results.append((tc, result))

        return [r for _, r in results]

    async def _execute_single(
        self,
        tool_call: ToolCall,
        context: ToolContext,
        channel: Channel,
    ) -> ToolResult:
        """执行单个工具（含 hook、超时、事件发射）"""
        tool = self.registry.get(tool_call.name)

        # ── Pre-hook ──
        for hook in self.hooks:
            hook_result = await hook.pre(tool_call, context)
            if hook_result and hook_result.blocked:
                return hook_result.tool_result

        # Plan-only 检查
        if self.config.plan_only and tool.tool_type == "write":
            return ToolResult(
                output="当前为 plan-only 模式，写类工具已被拦截。"
                       "请关闭 plan-only 开关后再执行写操作。",
                is_error=True,
            )

        # ── 发射 tool_call_start ──
        await channel.emit(Event(
            type="tool_call_start",
            timestamp=now_ms(),
            turn=context.turn,
            data={
                "tool_call_id": tool_call.id,
                "tool_name": tool_call.name,
                "arguments": tool_call.arguments,
                "tool_type": tool.tool_type,
            },
        ))

        # ── 执行（带超时）──
        start_time = time.monotonic()
        try:
            result = await asyncio.wait_for(
                tool.execute(tool_call.arguments, context),
                timeout=tool.timeout_ms / 1000,
            )
            status = "success"
        except asyncio.TimeoutError:
            result = ToolResult(output="工具执行超时", is_error=True)
            status = "timeout"
        except Exception as e:
            result = ToolResult(output=f"工具执行异常: {e}", is_error=True)
            status = "error"

        duration_ms = int((time.monotonic() - start_time) * 1000)

        # ── Post-hook ──
        for hook in self.hooks:
            await hook.post(tool_call, result, context)

        # ── 发射 tool_call_end ──
        await channel.emit(Event(
            type="tool_call_end",
            timestamp=now_ms(),
            turn=context.turn,
            data={
                "tool_call_id": tool_call.id,
                "tool_name": tool_call.name,
                "duration_ms": duration_ms,
                "status": status,
            },
        ))

        return result

    def _classify(
        self, tool_calls: list[ToolCall]
    ) -> tuple[list[ToolCall], list[ToolCall]]:
        """分类：读类 / 写类"""
        read_calls = [
            tc for tc in tool_calls
            if self.registry.get(tc.name).tool_type == "read"
        ]
        write_calls = [
            tc for tc in tool_calls
            if self.registry.get(tc.name).tool_type == "write"
        ]
        return read_calls, write_calls
```

### 3.4 Hook 框架

```python
from abc import ABC, abstractmethod
from dataclasses import dataclass

@dataclass
class HookResult:
    blocked: bool = False
    tool_result: ToolResult = None

class ToolHook(ABC):
    """工具拦截位基类"""

    @abstractmethod
    async def pre(self, tool_call: ToolCall, context: ToolContext) -> HookResult | None:
        """执行前拦截。返回 HookResult(blocked=True) 可阻止执行。"""
        pass

    @abstractmethod
    async def post(self, tool_call: ToolCall, result: ToolResult, context: ToolContext):
        """执行后拦截。"""
        pass


class NoOpHook(ToolHook):
    """空实现 hook（本章默认使用）"""

    async def pre(self, tool_call, context):
        return None  # 不拦截

    async def post(self, tool_call, result, context):
        pass  # 不处理
```

### 3.5 LLM 重试

```python
async def retry_with_backoff(func, max_retries=3, base_delay=1.0):
    """指数退避重试"""
    last_error = None
    for attempt in range(max_retries + 1):
        try:
            return await func()
        except RetryableError as e:
            last_error = e
            if attempt < max_retries:
                delay = base_delay * (2 ** attempt)  # 1s, 2s, 4s...
                await asyncio.sleep(delay)
            else:
                raise
        except NonRetryableError:
            raise  # 鉴权失败等不重试

    raise last_error


# 可重试的错误码
RETRYABLE_STATUS_CODES = {429, 500, 502, 503, 504}
NON_RETRYABLE_STATUS_CODES = {400, 401, 403, 404}
```

## 5. 测试策略

### 5.1 单元测试

| 模块 | 测试重点 |
|------|---------|
| `StateMachine` | 所有合法转换路径、非法转换抛异常、终态判断 |

### 5.2 集成测试

| 场景 | 测试流程 | 预期结果 |
|------|---------|---------|
| **单轮完成** | 用户消息 → LLM 无工具调用 → final_reply | 1 轮即终止 |
| **多轮完成** | 用户消息 → LLM 工具调用 → 工具结果 → ... → final_reply | N 轮后终止 |
| **达到 max_turns** | 设置 max_turns=2 → 两轮后强制终止 | turn_end(reason="max_turns") |
| **用户取消** | 循环中设置 cancel → 检查清理 | cancelled 事件 + 状态一致 |
| **工具超时** | 注册超时工具 → 验证超时处理 | 结果回填为 timeout error |
| **工具异常** | 注册抛异常工具 → 验证 error 回填 | 结果回填为 error message，循环继续 |
| **Plan-only 模式** | 开启 plan_only → 写类工具被拦截 → 计划输出 | 写类工具返回拦截信息 |
| **读类并发** | 一轮中 2 个读类工具 → 验证并发执行 | 两个工具几乎同时开始 |
| **写类串行** | 一轮中 2 个写类工具 → 验证串行执行 | 第二个在第一个完成后才开始 |

## 6. 错误处理策略汇总

| 层级 | 错误类型 | 处理方式 | 是否终止循环 |
|------|---------|---------|:------------:|
| LLM | API 限流 (429) | 指数退避重试，最多 3 次 | 重试耗尽则终止 |
| LLM | 鉴权失败 (401/403) | 不重试，发射 `error` 事件 | ✅ |
| LLM | 响应格式错误 | 发射 `error` 事件 | ✅ |
| LLM | 超时 | 发射 `error` 事件 | ✅ |
| 工具 | 不存在 | 结果回填为 error message | ❌ |
| 工具 | 执行异常 | 结果回填为 error message | ❌ |
| 工具 | 超时 | 结果回填为 timeout error | ❌ |
| 系统 | 用户取消 | 发射 `cancelled` 事件，清理 | ✅ |

> **核心原则**：工具层面的错误不终止循环——让模型看到错误信息后自我修正。只有 LLM 调用层面的不可恢复错误才终止整个循环。

## 8. 依赖关系

```
         ┌──────────┐
         │ config   │ ◀── 所有模块依赖
         └────┬─────┘
              │
         ┌────┴─────┐
         │ types    │ ◀── 所有模块依赖
         └────┬─────┘
              │
    ┌─────────┼─────────┐
    ▼         ▼         ▼
┌───────┐ ┌───────┐ ┌────────┐
│ event │ │  llm  │ │  tool  │
└───┬───┘ └───┬───┘ └───┬────┘
    │         │         │
    └─────────┼─────────┘
              │
         ┌────┴─────┐
         │  loop    │ ◀── 顶层编排
         └──────────┘
```

- `config` 和 `types` 是基础层，无外部依赖
- `event`、`llm`、`tool` 是中间层，依赖基础层
- `loop` 是顶层，编排所有中间层模块
- `mode`（plan_only、cancel）横切关注点，被 `loop` 和 `tool` 引用
