# ZXCode 命令系统规格

## 背景

ZXCode 目前的命令分发是 `app.py` 里一串 `if/elif` 硬编码：命令元数据（名称、描述、用法、参数提示）散落在各分支里，没有统一注册入口，不支持别名和补全，命令处理直接依赖 Textual 的 App 方法。新增一个命令就要改主文件、手工接入输入框和状态栏，测试也只能走完整 UI 流程。

本章把命令层重构成四块：集中式注册中心、统一解析器、UI 控制接口、事件分流器，让命令"注册即用"，并补齐别名、Tab 补全、状态栏联动和未知命令引导。

## 目标用户

- 终端使用者：希望命令可发现（`/help` + Tab 补全 + 状态栏提示）、大小写不敏感、别名顺手、输错有引导。
- 扩展开发者：希望给 ZXCode 加命令时只写元数据和处理函数，不碰输入框、渲染和对话流。

## 能力清单

- 集中式注册中心：命令以元数据注册，包含名称、别名、描述、用法、类型、参数提示、隐藏标记与处理函数。
- 注册冲突检测：名称或别名重复（含大小写变体）时注册直接失败，问题在启动期暴露。
- 统一解析器：识别 `/` 前缀输入，首个空格前是命令名、之后是参数；命令名转小写，大小写不敏感。
- 三类命令：纯本地、影响 UI 状态、AI 对话流（预设提示词送进对话）。
- UI 控制接口：命令只依赖抽象接口（显示系统消息、发送用户消息、切换模式、查 token、刷新状态、退出、弹选择列表），不直接依赖具体终端渲染框架。
- 回车分流器：用户回车入口先判断是否为命令；是命令走本地分发，不是命令才送给 AI。
- 别名支持：命令可声明一个或多个别名，与主名称等价。
- Tab 补全：单匹配直接补全、多匹配弹出选择列表、无匹配不动作；隐藏命令不参与补全但可直接执行。
- 状态栏联动：常驻显示当前模式（执行/计划）与高频命令提示。
- 未知命令引导：未知命令统一提示并引导到帮助入口。
- 内置命令集：帮助、上下文压缩、清空对话、模式切换、会话管理、记忆管理、权限管理、综合状态、代码审查。

## 非功能要求

- **行为兼容**：现有 9 个命令（帮助、清空、退出、切模型、计划模式、压缩、恢复、会话、笔记）迁移后行为不变，原有测试全部通过。
- **可测试性**：注册、解析、补全、分发是纯逻辑，不依赖 UI 即可单测；UI 适配器可用无头测试覆盖。
- **健壮性**：单条命令运行期异常被捕获并提示，不中断应用；注册冲突启动即失败，不静默吞掉。
- **效率**：解析与补全在命令数量级内完成；注册表仅存内存，不引入索引、持久化或外部依赖。
- **安全**：AI 类命令的预设提示词只作为提示注入，不执行；命令实现沿用现有安全策略（写类操作仍需确认）。

## 设计骨架

### 注册中心

内存注册表，保存命令元数据。提供注册（含冲突校验）、按名称或别名查询（大小写不敏感）、可见命令枚举、前缀补全查询。命令按类型执行，元数据中的类型决定走哪条执行路径。

### 命令分类

- **纯本地**：只读本地状态或做纯计算，不改变界面结构；结果通过 UI 接口回报。
- **影响 UI 状态**：改变界面或会话显示状态（清空对话、切换模式、恢复会话渲染、退出等）。
- **AI 对话流**：需要把预设提示词送进对话流让模型处理，走 A+B 混合语义（见下）。

### AI 类命令的 A+B 混合语义

AI 类命令由命令处理器产出两部分：

- **A（触发消息）**：一条简短的用户消息，作为真实用户消息进入对话、进入 JSONL 存档、计入轮次，用户可见可审计。
- **B（预设提示词）**：完整的指令文本作为当次请求的 system 侧注入，不进存档、不进压缩预算、不计轮次。

效果：存档里留有"用户执行过该命令"的记录，恢复后语义不丢；长预设词不污染历史、不被压缩破坏、不触发自动笔记误判。

### UI 控制接口

一组抽象能力，覆盖命令需要的界面操作：显示系统消息、发送用户消息、切换模式、查询 token 估算、刷新状态栏、退出、弹出选择列表。Textual 适配器实现这些能力，命令实现只面向接口。

### 事件分流器

用户回车入口先走解析器：`/` 前缀输入解析为命令调用并分发，非命令输入原样送 AI 生成。AI 类命令由分发器组装 A+B 请求后复用现有生成与存档链路。

### 补全器

基于注册表前缀匹配。单匹配直接替换输入；多匹配弹出选择列表（复用现有模态选择模式）；隐藏命令排除在外。

### 状态栏

命令元数据可声明是否为高频命令。状态栏常驻显示当前模式与高频命令提示；模式切换时同步刷新。

## Out of Scope

- 插件化动态加载命令（运行时从外部目录或包加载）。
- 远程/共享命令（多机同步、云端注册表）。
- 非 `/` 前缀的自定义触发词。
- POSIX 风格参数解析（`--flag`、子命令参数化）。
- 多用户命令权限体系（命令级 ACL）。
- 非 Textual 渲染后端适配（接口预留，本期不实现第二后端）。
- 权限规则的在线编辑（本期仅查看/占位，编辑仍走配置文件）。
- 代码审查的实际接入（本期仅注册占位，后续接 `ocr` CLI）。
