# ZXCode 规则引擎验收清单

每一项必须可勾选、可观测。

## 加载与校验

- [ ] 临时项目 `.zxcode/rules/` 放入一条「事件 + 条件 + 动作」合法规则，启动后 `/rules` 能看到该规则。
- [ ] 规则文件缺事件或缺动作时，加载失败且错误信息包含文件路径与规则标识。
- [ ] 事件名不在事件目录内时，加载失败并给出规则标识（grep 错误输出含规则标识）。
- [ ] reject 出现在非 pre_tool_use 事件时，加载失败。
- [ ] pre_tool_use 带 async 标记时，加载失败。
- [ ] 动作类型缺必填字段（如 command 无 command、prompt 无 prompt、http 无 url、agent 无 name）时，加载失败并定位规则。
- [ ] 同一文件内规则标识重复时，加载失败。

## 条件匹配

- [ ] exact 操作符：字段值完全相等时命中，否则不命中。
- [ ] ne 操作符：字段值不相等时命中。
- [ ] regex 操作符：按正则匹配命中；非法正则按不匹配处理且不抛异常。
- [ ] glob 操作符：按 glob 匹配命中（如 `*.py` 匹配 `main.py`）。
- [ ] 组合 all：所有条件满足才命中；任一不满足则不命中。
- [ ] 组合 any：任一条件满足即命中。
- [ ] 同一条件组混用 all/any 时，加载失败。
- [ ] 无条件规则：事件触发即执行。

## 动作执行

- [ ] command 动作：条件命中后执行命令，日志出现命令输出。
- [ ] command 动作受安全策略约束：default 模式需要确认，strict 模式无 allow 规则即拒绝。
- [ ] prompt 动作：注入的提示词出现在本轮请求中（FakeClient 收到的消息可查见）。
- [ ] http 动作：指向本地测试服务器时，服务器收到请求且日志记录响应状态。
- [ ] agent 动作：返回「未实现」占位结果，不实际启动子进程。
- [ ] 模板变量：`事件名/工具名/文件路径/消息内容/错误信息/工具参数字段` 均被替换为实际值。
- [ ] 未定义模板变量替换为空串，动作不报错。

## 执行控制

- [ ] once 规则：同一会话内触发两次，动作只执行一次（标记文件只有一次写入）；重启 ZXCode 后新会话可再次触发一次。
- [ ] async 规则：动作在后台执行，主流程不等待；主轮次完成后标记文件出现。
- [ ] 超时动作：动作睡眠超过 timeout，被终止并记日志，Agent 主流程正常结束。
- [ ] pre_tool_use 不允许 async（加载期拒绝 + 执行器防御性拒绝）。

## 拦截

- [ ] pre_tool_use 规则命中 reject：工具本体不执行（计数为 0）。
- [ ] 拦截后工具结果为失败，错误信息包含拒绝原因。
- [ ] 下一轮请求中包含该工具错误结果，LLM 可看到拒绝原因（FakeClient 历史可查见）。
- [ ] 多条 reject 规则命中时，按声明顺序取第一条拒绝原因。
- [ ] reject 求值同步完成，不进入后台队列。

## 错误隔离

- [ ] 动作执行抛异常时，本轮 Agent 循环正常完成，无 traceback 泄漏到界面。
- [ ] Hook 日志包含 Hook（规则）标识。
- [ ] 消息级/轮次级 Hook 异常不中断循环，后续事件仍触发。

## 管理命令

- [ ] `/rules` 列出全部已加载规则（标识 + 事件）。
- [ ] `/rules <标识>` 显示该规则详情（事件、条件、动作、控制项）。
- [ ] 修改规则文件后 `/rules reload` 生效，新规则出现在列表。
- [ ] 重载遇到非法规则时，旧规则集保留且界面提示错误。

## 端到端验收

- [ ] 临时项目规则集包含：无条件 prompt 注入 + pre_tool_use reject + once + async + 超时 + 变量占位。
- [ ] 驱动一次完整对话：注入出现在请求、被 reject 的工具不执行且原因回灌、once 只执行一次、async 后台完成、超时不中断。
- [ ] `python -m unittest discover -s tests -v` 全量通过。
