# ZXCode 子工作者系统验收清单

每一项必须可勾选、可观测。

## 角色加载

- [ ] 项目 `.zxcode/workers/` 放入合法角色，启动后可通过统一工具入口按角色名调用。
- [ ] 项目、用户、内置同放同名角色时，模型使用项目级定义（优先级覆盖）。
- [ ] 坏 frontmatter 的角色文件被跳过且日志记录文件名，不阻断其它角色加载。
- [ ] 角色 frontmatter 的角色名缺失时跳过并记录。
- [ ] 角色声明工具白名单后，子对话的模型工具定义只含白名单 + 系统级工具。
- [ ] 角色声明黑名单后，黑名单工具从子对话工具定义中移除。
- [ ] 角色可声明模型与最大轮次，子任务按声明执行。

## 统一工具入口与嵌套防线

- [ ] 工具列表中子工作者工具只出现一次，不随角色数量变化。
- [ ] 通过类型参数选择角色后，同一工具返回不同角色的行为。
- [ ] 子工作者内再次调用子工作者工具时，返回嵌套禁止错误，且该工具在子对话工具定义中不可见。
- [ ] 全局禁止列表在任何模式（定义式/Fork/后台）下都生效。

## 定义式执行

- [ ] 定义式子任务的消息历史为空对话 + 角色系统提示 + 任务用户消息，不含父对话历史。
- [ ] 任务描述直接注入为第一条用户消息，不进入交互等待。
- [ ] 模型返回无工具调用的助手消息后任务完成，结果等于最后一条文本。
- [ ] 角色指定独立模型时子任务使用该模型；调用参数可覆盖。
- [ ] 子任务失败时返回结构化失败原因（含任务标识与错误信息）。

## Fork 式执行

- [ ] Fork 子任务的历史包含父对话全部消息。
- [ ] Fork 子任务首条消息包含强硬指令：不能再 Fork、不主动对话、不请求确认、直接使用工具、报告控制字数并按结构化字段输出。
- [ ] Fork 子任务工具集与父对话一致（复用父工具集）。
- [ ] Fork 模式强制进入后台，不产生前台阻塞。
- [ ] Fork 首请求与父对话前缀一致（FakeClient 收到的请求前缀可比较）。

## 隔离与共享

- [ ] 两个并发子任务的消息历史互不包含对方内容。
- [ ] 子任务的权限审批记录独立，不影响主对话审批状态。
- [ ] 子任务的 token 计数独立累计，主对话计数不受影响。
- [ ] 子任务与主对话共享同一个 LLM 客户端、Hook 引擎与文件系统实例。

## 工具过滤

- [ ] 定义式角色白名单生效：白名单外工具不可见。
- [ ] 后台子任务在角色基础上叠加更严格白名单：默认只保留只读与搜索类工具。
- [ ] 三种模式（定义式/Fork/后台）过滤结果稳定可复现。

## 后台任务管理

- [ ] 显式指定后台的任务立即返回任务标识，主对话不等待。
- [ ] 前台任务超过时间阈值后自动转为后台，主对话恢复可用。
- [ ] 用户手动切换（ESC）后前台任务转为后台。
- [ ] 前台转后台后运行中的实例不重启，任务标识不变，最终结果来自同一实例。
- [ ] `/workers` 列出全部后台任务（标识、角色、状态、token、耗时）。
- [ ] `/workers <标识>` 显示单任务详情。
- [ ] 终止命令后任务状态变为已终止，不再产生完成通知。
- [ ] 后台任务完成后，主对话异步出现结构化通知（任务标识、角色、状态、结果摘要、token、耗时），且当前轮次不被打断。

## 内置角色与 Hook

- [ ] 代码探索、计划制定、通用全能三个内置角色可解析并可调用。
- [ ] 验证角色默认不可用；配置开关启用后可调用。
- [ ] 子任务中 Hook 引擎生效：拦截规则拒绝工具时，子任务收到拒绝原因并调整行为。

## 端到端验收

- [ ] 临时项目驱动一次定义式子任务：注入任务 → 无工具调用即完成 → 结果等于最后文本。
- [ ] 临时项目驱动一次 Fork 子任务：历史继承、指令注入、强制后台、完成通知异步回流。
- [ ] 嵌套创建被全局禁止，返回错误且不产生子子任务。
- [ ] `python -m unittest discover -s tests -v` 全量通过。
